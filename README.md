## 💬 私密聊天室

一个没有历史记录的聊天室：随机昵称、读后才焚、自定义销毁时长、成员列表、一键清屏。

```bash
cd private-chat
node server.js        # 零依赖，纯 Node 内置 WebSocket
# 本机: http://localhost:3000
```
