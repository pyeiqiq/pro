## 💬 私密聊天室

一个没有历史记录的聊天室：随机昵称、读后才焚、自定义销毁时长、成员列表、一键清屏。

```bash
cd private-chat
node server.js        # 零依赖，纯 Node 内置 WebSocket
# 本机: http://localhost:3000
```

## 🍉 RE:0 合成大西瓜

基于 Matter.js 物理引擎的「合成大西瓜」同人小游戏。RE:Zero 角色进化链：昴 → 艾米 → 蕾姆 → 拉姆 → 贝蒂 → 帕克 → 菲鲁特 → 库珥修 → 罗兹瓦尔 → 莱傲天 → 强欲魔女。相同角色相撞即合成升一级，两个「强欲魔女」相撞触发**终极大爆炸**（震屏 + 冲击波 + 500 分）。带连击、粒子、音效与最高分本地存档。

```bash
cd suika-re0
# 直接用浏览器打开 index.html 即可游玩（首次需联网加载一次 Matter.js）
```
