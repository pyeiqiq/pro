资料库使用说明

这是 Stan 工作室资料库 的示例文件，用来演示资料库的展示、分类与分享能力。（随时可在「管理」面板删除）

当前模块

已上线 左侧分类树 · 右侧资料列表 · 搜索 · 复制分享链接 · 文档管理

使用方式

查看：点击每行右侧的「查看」按钮直接打开；HTML / PDF 在浏览器内查看，其他格式自动下载。

分享：点击「复制链接」即获得直链，发给同事后对方可直接打开。链接格式：

https://pyeiqiq.github.io/pro/library/files/<分类id>/<文件名>

搜索：顶部搜索框按文件名、描述、标签过滤。

管理：右上角「管理」按钮，输入 GitHub Token 即可在线新增/删除分类、上传/删除资料。

分类建议

预置四个顶级分类，可自由增删或建立子分类：

品牌调研技术研究产品资料会议与客户

协作约定

WorkBuddy 上生成的文件（HTML 报告、PDF 导出、表格等）可直接告诉我「把 X 上传到资料库的 Y 分类」，我会在仓库里建好文件并更新索引，再把分享链接给你。
