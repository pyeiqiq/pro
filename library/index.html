    连接 GitHub

    Token 仅保存在本机浏览器（localStorage），只向 api.github.com 发送，用于提交仓库改动。
    建议使用仅含 repo 权限的 Token；不要在不信任的设备上使用，泄露后可修改仓库内容。
    获取：GitHub → Settings → Developer settings → Personal access tokens（勾选 repo）。
