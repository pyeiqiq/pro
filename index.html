工具 01 · 私密聊天室

私密聊天室临时会话，阅后即焚

一个不保留历史记录的聊天室：进入后自动分配随机昵称，每条消息可在被阅读后按设定时长自动销毁。适用于需要短暂留痕的沟通。

🎭
随机昵称
进入后自动分配，刷新即更换，不留存身份。
⏱️
自定义销毁
3秒 / 10秒 / 20秒 / 60秒 / 5分钟 / 永久，由发送者决定。
👁️
读后才焚
消息未被查看不计时，回到页面看到后才开始销毁。
👥
成员列表
实时显示在线成员，进出与改名一目了然。
🧹
一键清屏
永久消息过多时，可仅清除本地屏幕，不影响他人。
🔗
即点即入
分享链接一键复制，支持局域网或隧道公网地址。

运行方式

这是一个零依赖的 Node 服务（内置 WebSocket，纯手写协议，无需安装依赖）。

cd private-chat
node server.js
# 本机打开 http://localhost:3000
# 同 WiFi 设备使用页面内提供的局域网地址
查看源码 ↗
技术说明：消息仅存在于内存中，服务端不落盘；销毁计时在浏览器端完成（以 IntersectionObserver 判断消息是否真正被看到）。跨网络使用时，可配置 cloudflared / ngrok 隧道，前端已自动支持 wss。
