TOOL 01 · PRIVATE CHAT

💬 私密聊天室
阅后即焚，话不落地

一个没有历史记录的聊天室：进来自动分配一个「颜色 + 动物」的随机昵称， 每条消息被读到才开始倒计时销毁——3 秒、20 秒、5 分钟，或者干脆「永久」。 聊完即焚，谁也翻不了旧账。

🎭
随机昵称
进来自动分配，刷新就换一个，不留痕迹。
⏱️
自定义销毁
3秒 / 10秒 / 20秒 / 60秒 / 5分钟 / 永久，发送者说了算。
👁️
读后才焚
消息没被看到就不倒计时，切回来看到才开始销毁。
👥
成员列表
右侧实时显示在线的人，谁进谁出、谁改了名一目了然。
🧹
一键清屏
永久消息攒太多？点一下，只清自己的屏幕，不影响别人。
🔗
即点即入
分享链接一点复制，局域网或隧道公网地址，对方打开就能进。

怎么跑起来

这是一个零依赖的 Node 服务（内置 WebSocket，纯手写协议，不装任何包）。

cd private-chat
node server.js
# 本机打开 http://localhost:3000
# 同 WiFi 的朋友用页面里分享的局域网地址
查看源码 ↗
💡 技术备注：消息只存在内存里、服务器不落盘；销毁计时在浏览器端完成（IntersectionObserver 判断「真的看到」）。 想跨网络用？配个 cloudflared / ngrok 隧道即可，前端已自动支持 wss。
